完整页面样板

用实际账户内容检查信息密度、卡片关系和操作顺序。五类页面共用导航、标题边界与尺寸规则，可切换主题和真实视口宽度。

打开完整页面 ↗

视口切换通过改变页面实际可用宽度完成；文字保持原尺寸。手机上使用「打开完整页面」查看当前样板。

01 / OVERVIEW

概览模板

用于数据总览、节点摘要。标题与内容同边界；总额、资产分项与趋势组合为主区，会员卡与关联入口放次栏；不足 860px 时按资产、会员、关联入口顺序转单列。

02 / COLLECTION

列表模板

用于钱包记录、节点客户、设备管理。整页上限 1280px，搜索最长 360px；金额、时间、状态与操作使用稳定列宽。手机保留时间，将完整编号放入详情。返回保留筛选与位置。

03 / DETAIL

详情模板

用于流水明细、连接详情、权益说明。整页上限 1040px，标题与详情共用边界。结果和对象优先；进度侧栏不跟主卡强行等高，完整字段可换行。

04 / SETTINGS

设置模板

用于资料、安全与通知偏好。面包屑、标题、表单和页脚共同限制在 840px；内部不再居中收窄。字段分组有说明，必填标记明确，保存结果在操作附近出现。

05 / TASK FLOW

多步任务模板

用于身份验证、连接交易所、充值与提现。整页上限 1040px，步骤栏 192px、栏距 24px；任务卡按内容自然增高。相关短字段成对，手机转单列。前一步保留输入，提交前核对。

统一对齐基线：页面容器 → 标题 / 卡片外框 / 页脚；卡片内边距 24px，手机 16px；字段间距 24px，标签与控件 8px。下拉箭头为 20px 图标，右侧留 12px，文字右侧预留 44px。留白由内容关系决定，禁止通过空卡或固定最小高度填满页面。

模块组合边界

卡片承载一个独立对象或任务；同一对象的连续字段使用分组与分隔线。卡片内不反复嵌套卡片。单个操作组只保留一个主要动作，其他动作使用次按钮或文字入口。

品牌资产例外

会员卡沿用指定 App 原稿，保留其材质与等级识别；Logo 完整收在卡面内，不覆盖文字或进度。例外仅作用于会员卡本身，外侧容器遵守统一间距与尺寸。

OPENX / IMPLEMENTATION单一规则来源

规范与代码保持一致

所有基础值保存在 tokens.json。字体、间距、尺寸、色彩、图层和组件时长由同一文件导出；页面引用语义角色，组件引用尺寸变量。

tokens.json→build-tokens.mjs→CSS / JS / 断点
文件责任使用规则
tokens.json唯一基础数值来源颜色、字阶、布局、组件、动效、图层；修改先发生在此文件
tokens.css完整 CSS 变量布局、字号、行高、字重、按钮尺寸、状态时长等均可直接引用
tokens.js页面运行时数据规范表格、宽度示意和交互规则读取 OPENX_TOKENS
responsive.css由断点生成的布局辅助类媒体查询边界在生成时写入；不在媒体查询中使用无效的 CSS var()
breakpoints.json其他构建环境的断点输入手机 ≤ 767、平板 768–1199、桌面 ≥ 1200；项目中不得再维护第二套边界
build-tokens.mjs可重复执行的导出脚本在规范目录运行 node build-tokens.mjs，更新所有生成文件
motion-runtime.js / CSS共享动效与减少动态适配在页面业务脚本之后加载；弹窗、抽屉、局部内容更新、首次进入与忙碌状态渐进增强，不延迟业务操作
select-menu.js / CSS下拉列表与键盘交互保留原 select 表单值与 input/change 事件；动态字段自动接入，主题与减少动态模式同步
calendar-picker.js / CSS日期与区间选择单日、双月区间、年月快选共用视觉；保留原 date 字段值、事件和边界校验，日期演练与业务筛选使用同一组件

继承关系

颜色先按品牌与灰阶定义，再映射明暗主题中的 canvas、surface、text、border、action；组件通过这些角色取值。官网按钮和账户按钮保持各自原有形态，状态时长分别定义。

内容与文案

标题末尾无标点；操作文案写明对象和动作。简繁语言对应 SC / TC 字库。长标题自然换行；金额、错误原因、资格条件与最终确认信息完整呈现。

应用到产品页面的顺序
  1. 按已有功能选择模板，保留入口、字段、资格条件和计算逻辑
  2. 接入统一字体与 Tokens，再组合真实需要的组件
  3. 把该流程的加载、空、错误、成功和返回路径接入同一布局
  4. 用长内容、宽屏与手机核对实际排版，最后统一进行完整审核
