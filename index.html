完整页面样板

用实际账户内容检查信息密度、卡片关系和操作顺序。五类页面共用导航、标题边界与尺寸规则，可切换主题和真实视口宽度。

打开完整页面 ↗

视口切换通过改变页面实际可用宽度完成；文字保持原尺寸。手机上使用「打开完整页面」查看当前样板。

01 / OVERVIEW

概览模板

用于数据总览、节点摘要。标题与内容同边界；总额、资产分项与趋势组合为主区，会员卡与关联入口放次栏；不足 860px 时按资产、会员、关联入口顺序转单列。

02 / COLLECTION

列表模板

用于钱包记录、节点客户、设备管理。整页上限 1280px，搜索最长 360px；金额、时间、状态与操作使用稳定列宽。手机保留时间，将完整编号放入详情。返回保留筛选与位置。

03 / DETAIL

详情模板

用于流水明细、连接详情、权益说明。整页上限 1040px，标题与详情共用边界。结果和对象优先；进度侧栏不跟主卡强行等高，完整字段可换行。

04 / SETTINGS

设置模板

用于资料、安全与通知偏好。面包屑、标题、表单和页脚共同限制在 840px；内部不再居中收窄。字段分组有说明，必填标记明确，保存结果在操作附近出现。

05 / TASK FLOW

多步任务模板

用于身份验证、连接交易所、充值与提现。整页上限 1040px，步骤栏 192px、栏距 24px；任务卡按内容自然增高。相关短字段成对，手机转单列。前一步保留输入，提交前核对。

统一对齐基线：页面容器 → 标题 / 卡片外框 / 页脚；卡片内边距 24px，手机 16px；字段间距 24px，标签与控件 8px。下拉箭头为 20px 图标，右侧留 12px，文字右侧预留 44px。留白由内容关系决定，禁止通过空卡或固定最小高度填满页面。

模块组合边界

卡片承载一个独立对象或任务；同一对象的连续字段使用分组与分隔线。卡片内不反复嵌套卡片。单个操作组只保留一个主要动作，其他动作使用次按钮或文字入口。

品牌资产例外

会员卡沿用指定 App 原稿，保留其材质与等级识别；Logo 完整收在卡面内，不覆盖文字或进度。例外仅作用于会员卡本身，外侧容器遵守统一间距与尺寸。

统一浮层、长内容、键盘与触摸行为，让同一任务在桌面和手机上都能完整完成。

01

选择合适的承载方式

页面

完整多步流程、身份验证、提现和 API 连接使用独立页面。URL 可以回到步骤或记录；每次切换把焦点放到步骤标题。

弹窗

单一决策或短任务，例如解除授权、修改昵称、确认登出。最大宽度 480px；说明、内容与操作一眼可辨，不在确认弹窗里塞完整长流程。

抽屉

需要保留列表上下文的用户详情、记录详情与筛选。桌面最大宽度 480px；多字段长期编辑或需要深链接的完整详情转页面。

轻量浮层

下拉选项和补充说明贴近触发对象；靠近视口边缘自动翻转。内容太长时内部滚动，不让整页横向滚动。

一次只进行一个模态任务

弹窗内的选单和提示属于该弹窗；关闭最上层只影响最上层。放弃编辑确认替换当前内容，不叠加第三层对话框。

右上角统一使用 × 关闭

弹窗与抽屉右上角使用 20px × 图标，不放“关闭”文字；点击区 44 × 44px，aria-label 说明对象，例如“关闭用户详情”。悬停仅使用中性灰阶，键盘焦点为 2px 清晰描边；底部仍可保留取消。

关闭路径保持一致

只读浮层可点遮罩关闭；有未保存内容时走放弃确认。Esc 与右上角 × 规则相同，不能绕过草稿确认；完成关闭后返回原触发按钮。

焦点留在活动对话框

打开时聚焦标题或首个字段，Tab 在其中循环；风险确认优先聚焦取消。关闭回到触发按钮；该按钮已移除时回到相邻列表行。

遮罩负责隔离

以品牌 Ink 的 48% 透明度覆盖页面，不额外增加玻璃模糊。底层设为 inert；对话框具备标题关联和 modal 语义。

键盘与焦点依据 WAI-ARIA Dialog 模式；层级数值与图标尺寸是 OpenX 的统一约定。

04

响应式内容优先级

≤767px手机 / 4 栏

单列内容、16px 页边距。表单字段一列；主要操作保持 44px 触摸高度。详情与列表切换后保留返回上下文。

768–1199px平板 / 8 栏

24px 页边距、收窄导航。筛选栏可以换行；文字与控件不压缩。次栏低于约定最小宽度时提前换行。

≥1200px桌面 / 12 栏

32px 页边距。内容在剩余工作区居中，最大宽度使用页面类型 token；大屏不整体放大字体与图标。

列表与表格

手机优先显示对象、金额、状态和主要操作；时间、编号、详情进入可展开行。需要横向比较的完整表格放在局部可滚动容器，并有可见滚动提示。

筛选与批量动作

搜索保留在列表上方；复杂筛选收进抽屉，入口显示已选数量。批量操作只在选中后出现，提供取消选择，不能遮挡记录末行。

文字与数字

标题自然换行且无末尾标点；金额与单位保持关联，极长数值降低一个字号级别后允许合理换行。地址、UID 可断行与复制，完整详情不省略。

触摸与放大

触摸设备不依赖 hover 显示按钮或关键提示；使用点击展开。200% 文本放大时控件自适应增高，不裁掉文字。布局最窄覆盖 320px。

05

校验、反馈与未保存内容

校验时机

初始不显示错误；首次离开已填写字段时校验，提交时检查全部。错误出现后随有效修改更新；提交失败将焦点移到首个错误，关联错误说明。

普通 Toast

复制、保存等非关键反馈显示 5 秒，可手动关闭；悬停或键盘焦点停留时暂停计时，最多同时 3 条。同一事件合并，不重复刷屏。

错误持续可见

字段错误留在字段下，直到修正。页面错误提供重试；重要交易结果保留在页面或记录里。Toast 不作为失败、付款结果和权限原因的唯一入口。

可中断的修改

只有值发生变化才标记未保存。放弃确认提供继续编辑与放弃修改；保存失败保留草稿。即时生效的主题、筛选不再叠加保存确认。

动效与等待

加载保留原空间，操作按钮保持宽度。常规反馈沿用现有按钮时长，浮层 220ms / 8px；减少动态偏好下取消位移动画。结果改变用文字和图标同步表达。

禁止假成功

提交、处理中与成功是三个独立状态。只有得到对应结果才更新完成态；超时或断线保留对象标识供重试或查询，不自动清空内容。

持续错误与非打断式通知参考 WAI-ARIA Alert 模式；5 秒仅用于可在页面再次确认的普通反馈。

使用共同断点、浮层层级和反馈 token，避免页面各自定义一套行为16 / 18

把已确认的改进变成规则

按适用场景复用组件，不把单页插图位置、示例金额和业务条件当成通用设计规范。

01 单层柔和高亮

已有边框的输入、下拉、整张选择卡：悬停、选中、聚焦只加强原边框。深色默认 #34343B，浅色默认 #CFCFD6；使用 border-hover 略微提亮。无边框的链接和图标按钮保留可识别的灰色焦点轮廓。

不采用：橙色双圈、额外 inset 阴影、Logo 区内部再画框。错误仍需文字原因和柔和错误边框，不能只换颜色。

02 图表骨架与颜色角色

趋势图共用保形曲线、柔和虚线网格、低透明面积、细竖纹和末点圆点。资产与奖励使用品牌橙；策略收益绿涨红跌，以累计收益相对 0 判断，亏损期间的短暂回升仍为红色。不同策略使用各自历史，不能复制同一条示例曲线。

缺口、无交易、无操作：水平延续上一有效值，下次有效时刻垂直更新；没有前值则不画零线。明细缺失显示“—”。图表不得改变点值或编造收益。

03 双线对照

OI 价格为橙线，持有量为中性灰线；两线分别以首个有效点为 100 归一化，标明“起点 = 100”和指标名称。价格可保留轻面积，第二条线不铺重叠面积。悬停与键盘查看同时返回两项值及时间；Tooltip 只在图表内定位。

价格指数OI 指数起点 = 100

不把价格和持有量的原始单位硬放在同一个无说明纵轴；无真实时间戳时不能编造日期。

04 详情侧栏

需要保留榜单上下文时，详情从右侧展开：桌面、平板最大 600px，手机全宽。顶部标题 20/28，× 图标 20px，点击区域 44×44px；正文独立滚动。Esc、遮罩和 × 关闭，焦点返回原入口；图表提示先消失，再关闭侧栏。
