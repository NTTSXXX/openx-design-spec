## 社媒配图与视频封面

入口：`index.html#social-media`。页面按排版规范、生图提示词、参考图套用切换，一次只呈现一个工作区。按知识、公告、方图公告、横竖采访和教程选择九套样张；支持查看底图、版位辅助线、原尺寸成稿、下载PNG、试填文案并自动测量换行及复制底图prompt与后期排版指令。`social-media-data.json`保留底图来源、实际修改记录、可编辑文字、官方Logo路径与坐标。

内部使用顺序：选版式 → 复制纯视觉Prompt生成完整底图 → 后期放入正式Logo与文字并导出。四套输出为1920×1080、1080×1920、1080×1350、1080×1080。公开Prompt统一为主体动作、构图、颜色材质、背景光照、留白与限制六项，250–450字。产品使用光滑镀银、哑光烤漆与玻璃，地面光滑无纹理；机器人搭配一件实体道具或最多两张相关icon卡片。人物保持真实照片风格。

制作工作台：上方直接替换底图与下载PNG，右侧按「文字 / 底图 / 说明」切换。九套版式的41个发布文字字段均可编辑，包含问题标题、互动问题、小字与Slogan；强调词单独设置。编辑自动切换为可编辑成稿，超限在对应字段提示并停止导出。替换底图支持本地PNG/JPEG/WebP（20MB以内）与拖入预览，默认完整显示；可切换铺满、缩放和水平/垂直位置，保留文字与Logo坐标。当前底图、文案、排版指令、原尺寸查看及PNG导出使用同一状态；辅助线不导出。各版式编辑在本页会话中保留，刷新恢复示例；底图仅在浏览器读取，不上传分析服务。底图恢复与文案恢复分别操作。

人物样张为生成的构图示例，正式采访需替换为实际照片或视频帧。官网参考只说明既有品牌来源；新样张按本轮元素预算、具象材质与自然光要求收敛。平台与生图资料来源见尺寸章节的折叠说明。

本轮界面改为章节侧边栏；方图及竖版公告固定上方品牌行、中间主视觉、下方文案，含下方居中样例。IP多视角原档与交互面板保存在assets/ip-bot及ip-bot，支持旋转、缩放、表情与动作预览。

知识海报以Owner提供的Figma完成品为基准，默认显示原稿参考；可切换生成底图与后期文字版。透明、遮罩、模糊与主视觉整体使用生成式处理，不拼接Figma素材层。横版IP知识案例使用机器人与两张icon卡片；另提供比特币前后景、以太坊斜向飞行、两卡伴飞三个方向。动态用前后景尺度差、斜向排列、10–15°机身倾斜与有限翼臂角度体现，关节自然、与道具留间隙，不抓取或承重。静态只真实光照；飞行允许一道顺运动方向的短橙色拖影和轻微背景速度模糊，角色与胸标清晰，不加粒子或多道光带。预览按原比例完整显示。

Logo区提供SVG下载、2048px宽透明PNG导出和SVG源码复制。3D面板提供鼠标跟随、拖拽旋转、滚轮缩放、可见缩放滑杆和重置；切换表情不重置视角。

## IP 机器人

独立入口：`index.html#ip-robot`，与社媒章节同级。构图与动态示例、角色结构/动作规范、机器人专属Prompt、参考图、多视角原档及3D交互集中在此；社媒工作区保留排版应用案例与入口链接。内容片段为 `ip-robot.html`，复制反馈与旧锚点展开由 `ip-robot.js` 独立处理。原有 `#sm-ip-assets` 和各机器人Prompt深链继续可用。


## 实际看图与提示词套用

运行 `node scripts/prompt-adapter-server.cjs`，打开 `http://127.0.0.1:6128/#sm-prompt-adapter`。本地服务使用本机已登录的 Codex CLI 读取上传图片，返回真实分析、无品牌名的底图Prompt和后期排版指令；不需要把API Key放进网页。仅静态托管无法运行这个服务，可复制折叠区指令在其他视觉AI使用。上传图片用于本次分析，任务结束清除临时副本。

每次外观输入只用最初的清晰原始照片或官方角色原档；完成图仅分析动作、构图与材质，不传像素给生成器。禁止将生成结果做第二、第三轮像素参考。原因、处理方法和查证来源见社媒章节“参考图质量与生成流程”。本轮清单与验证记录见 `DELIVERY-20261007.md`。
