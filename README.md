# OpenX ONE 设计规范

在线查看：https://nttsxxx.github.io/openx-design-spec/

包含色彩、品牌 Logo、字体层级、页面宽度、响应式布局、卡片、控件、状态、图表、动效、日期组件及交接规则。主入口为 `index.html`，保留现有规范 v1.3 的素材与交互。

本仓库只发布设计规范及运行依赖。更新原规范后，将 HTML、CSS、JavaScript、Tokens 和 assets 同步到本仓库并推送 `main`，GitHub Pages 会自动重新发布。

字体许可证随素材保留在 `assets/fonts/`。规范及品牌素材的权利归原权利方所有。
