个人中心流程与状态

从入口到完成，每个流程都定义下一步、异常原因和返回位置。下方按现有页面与业务规则整理。

既有业务边界

资格、金额、期限、权限与计算方式继续读取原业务来源。设计规则不新增门槛，不代替业务判断。

界面交付规则

下面的加载、报错、重试、焦点和草稿处理是后续页面必须呈现的交互标准，不表示现有网站已经全部实现。

进入→填写与核对→处理中→结果与下一步

展开任一领域查看完整清单。只读页面不强行添加提交步骤；空数据、没有筛选结果、读取失败必须分开。

01数据总览资产概览、趋势、会员身份与业务入口+
入口与步骤
个人中心首页 → 查看资产与会员状态 → 切换趋势区间或隐藏金额 → 前往对应业务页面。
进行中与完成
首次读取使用原尺寸骨架；区间切换保留图表外框。完成后显示时间区间、金额单位与同步结果，不弹成功 Toast。
空与失败
零资产仍显示 0；未知金额显示“—”。没有趋势数据给出原因；局部读取失败仅替换该区域并提供重新读取。
返回与禁用
从子页面返回保留原区间和金额可见性。尚未取得数据时不能显示虚构数值；业务入口是否可用服从原资格规则。
权限与未保存
未登录显示登录入口并保留返回地址。只读页面无未保存确认；金额可见性是显示偏好。概览不放常用管理、账户活动与分段权益色条。

02等级与权益当前等级、成长进度、权益与升级路径+

03交易指标筛选、详情、领取、发放、使用与续期+
入口与步骤
指标库 → 查看指标详情与资格 → 核对 TradingView 账户 → 确认领取 → 发放结果 → 使用说明；过期指标按既有规则进入续期。
进行中与完成
领取中保留指标名与目标账户，避免重复提交；用户可以返回指标库查看结果。成功显示授权状态、期限及 TradingView 使用入口。

权限与未保存
领取范围、发放时间、授权期限继续由原规则决定。未提交的账户名称可在当前流程内保留；离开时如有修改需确认放弃。

04钱包与充提记录资产、充值、提现核对、安全验证与交易追踪+
入口与步骤
钱包 → 选币种。充值：选网络 → 取得地址与 Memo / Tag。提现：填写网络、地址、数量 → 核对费用与到账数量 → 安全验证 → 提交 → 进度与详情。记录支持筛选和返回。
进行中与完成
获取地址、获取报价、发送验证码与提交分别显示忙碌态。提交完成只表示申请建立；待处理、处理中、已完成、未完成按交易状态分别显示。
空与失败
零余额、无筛选结果、交易不存在与读取失败分开呈现。地址不完整不得显示可用二维码；未完成交易保留原因、编号与详情。
返回与禁用
验证码冷却显示剩余时间；处理中阻止重复操作。余额不足、网络或地址不匹配、缺少 Memo、未勾核对、报价过期按原校验阻止提交。报价缺失返回填写；失败提现重新填写，不复用失效报价。
权限与未保存
报价、费用、到账数、余额和验证码条件沿用原规则。修改币种、网络、地址或数量使旧报价失效。返回记录保留筛选与滚动位置；验证码不跨会话保存。

05交易所 UID 授权选择交易所、验证归属、失效重连与解除授权+
入口与步骤
交易所设置 → UID 页签 → 选择交易所 → 输入 UID 与可选推荐链接 → 验证并授权 → 连接详情。
进行中与完成
验证中保留交易所和输入；成功显示归属信息、最近验证与管理入口。状态属于具体账户，不只显示一颗绿色标签。
空与失败
未连接显示选择交易所入口；验证失败和授权失效保留账户记录。账户不支持节点授权时说明资格原因并提供客服入口。
返回与禁用
失败可重新验证；失效可修改 UID 后重连。解除前说明影响，并提供保留授权。返回清单保留所选交易所。
权限与未保存
UID 仅确认节点归属，不赋予交易或提现权限。解除 UID 不解除 API；失败重试不创建第二份连接。UID 草稿可在当前流程内保留。

06交易所 API 连接用途、教程、金钥、权限校验与暂停管理+
入口与步骤
交易所设置 → API 页签 → 选择交易所与连接方式 → 按需查看教程 → 选择读取或合约交易用途 → 输入 Key / Secret → 校验 → 权限管理。
进行中与完成
分别说明金钥有效性、读取与合约权限校验进度；完成后列出每项权限。已暂停保留设置，并区分连接状态与执行开关。
空与失败
未连接显示添加入口；失效显示更新 Key；权限失败显示具体缺项与重新校验。保留交易所、用途与原连接记录。
返回与禁用
只读用途不能声称拥有交易权限；失效金钥不继续执行。解除前说明停止读取或执行，返回后继续原列表上下文。
权限与未保存
提现权限始终关闭；解除 API 不解除 UID。管理页 Key 遮罩、Secret 不回显。敏感输入仅当前流程暂存，离开或完成即清除，不写入 URL、日志或浏览器持久存储。

07身份验证证件、上传、人脸、个人与工作资料、审核结果+
入口与步骤
证件地区 → 验证方式 → 上传证件 → 人脸验证 → 确认个人信息 → 工作与行业资料 → 提交审核 → 结果与身份详情。
进行中与完成
上传逐项显示进度；审核中显示已提交项目，并允许离开后返回。只有通过结果显示已认证；详情中的身份信息遮罩。
空与失败
未开始给出所需资料与开始入口；补件定位到具体项目，保留已完成资料。提交失败不进入审核中；拒绝与技术错误分别说明下一步。
返回与禁用
返回上一步保留仍有效的选择；格式或必填校验在对应字段显示。补件回到上传，技术失败从失败环节重试，不强制重做已完成项目。
权限与未保存
可接受证件、地区、校验条件与审核结果沿用业务来源。离开未提交流程提醒未提交内容；敏感文件不持久缓存，不声称已永久保存。

08节点中心奖励、邀请、用户筛选、用户详情与备注+
入口与步骤
节点总览 → 奖励记录或用户管理 → 按考试状态、用户、UID、备注筛选 → 用户详情 → 编辑联系资料与备注。邀请支持复制及二维码；提取进入钱包提现流程。
进行中与完成
奖励与用户数使用同一记录来源；复制成功在原操作处反馈。备注保存完成后更新详情与列表；奖励状态区分待入账、已入账、已提取。

返回与禁用
关闭详情返回原用户行并保留筛选；备注保存失败保留草稿。没有可用链接时解释不能分享的原因，奖励提取条件由钱包和既有资格决定。

09个人资料昵称、UID、头像上传、裁切与保存+
入口与步骤
资料页 → 编辑昵称并保存；或更换头像 → 选择图片 → 调整裁切与缩放 → 保存。UID 可复制，身份与入会信息只读。
进行中与完成
读取图片与生成裁切分别显示忙碌反馈；保存完成同步侧栏与资料页。保留原头像直到新头像确认成功。
空与失败

取消昵称恢复原值；裁切面板可更换图片或恢复默认。保存中禁止重复提交；文件条件沿用已有校验，不自行修改限制。

仅编辑当前账户。昵称或头像有改动才出现放弃确认；裁切源图、缩放或位置变化均计为未保存。关闭后返回触发按钮。

10账户安全信箱、密码、双重验证、装置与安全活动+
入口与步骤
信箱：验证旧信箱 → 新信箱与验证码 → 完成。密码：当前密码、新密码、确认 → 验证 → 完成。2FA：说明 → 扫码 → 验证 → 保存恢复码 → 完成；停用另行验证。装置：选择其他装置 → 确认登出。
进行中与完成
发送、校验与保存都有具体动作名。成功更新安全方法和装置列表；2FA 只有完成恢复码确认后才显示已启用。

密码和验证码退出流程即清空；不显示在 URL 或记录中。未保存的普通输入可确认放弃；恢复码确认不得跳过。重新进入敏感流程按现有规则重新验证。

  • 返回保留有效筛选、上下文与滚动位置；失效的报价、验证码和授权不复用。

OPENX / BEHAVIORRESPONSIVE & OVERLAYS

复杂布局与交互规则

统一浮层、长内容、键盘与触摸行为，让同一任务在桌面和手机上都能完整完成。

01

选择合适的承载方式

页面

完整多步流程、身份验证、提现和 API 连接使用独立页面。URL 可以回到步骤或记录；每次切换把焦点放到步骤标题。

弹窗

单一决策或短任务，例如解除授权、修改昵称、确认登出。最大宽度 480px；说明、内容与操作一眼可辨，不在确认弹窗里塞完整长流程。

抽屉

需要保留列表上下文的用户详情、记录详情与筛选。桌面最大宽度 480px；多字段长期编辑或需要深链接的完整详情转页面。

轻量浮层

下拉选项和补充说明贴近触发对象；靠近视口边缘自动翻转。内容太长时内部滚动，不让整页横向滚动。

02

遮罩、层级与焦点

  1. 0页面内容常规布局与卡片
  2. 10固定导航页头、侧栏与局部吸顶
  3. 20下拉与弹出内容相对所属页面的选择器
  4. 30 / 40遮罩 / 对话框底层不可操作，锁定页面滚动
  5. 50 / 60Toast / Tooltip只属于当前活动层，不跨层显示
一次只进行一个模态任务

弹窗内的选单和提示属于该弹窗；关闭最上层只影响最上层。放弃编辑确认替换当前内容，不叠加第三层对话框。

右上角统一使用 × 关闭

弹窗与抽屉右上角使用 20px × 图标，不放“关闭”文字；点击区 44 × 44px，aria-label 说明对象，例如“关闭用户详情”。悬停仅使用中性灰阶，键盘焦点为 2px 清晰描边；底部仍可保留取消。

关闭路径保持一致

只读浮层可点遮罩关闭；有未保存内容时走放弃确认。Esc 与右上角 × 规则相同，不能绕过草稿确认；完成关闭后返回原触发按钮。

焦点留在活动对话框

打开时聚焦标题或首个字段，Tab 在其中循环；风险确认优先聚焦取消。关闭回到触发按钮；该按钮已移除时回到相邻列表行。

遮罩负责隔离

以品牌 Ink 的 48% 透明度覆盖页面，不额外增加玻璃模糊。底层设为 inert；对话框具备标题关联和 modal 语义。

键盘与焦点依据 WAI-ARIA Dialog 模式；层级数值与图标尺寸是 OpenX 的统一约定。

03

长内容与手机键盘

固定标题 ×
内容区域独立滚动
取消 主要操作
桌面
浮层距上下边缘至少 24px；最大高度为可视区减 48px。容器分 header / body / footer 三行，只有 body 滚动。
手机
≤767px 时抽屉成为全宽任务面板，完整表单使用可视区高度；短确认保留两侧 16px。顶部和底部加入 safe-area。
键盘弹起
表单随可视区域收缩；无法可靠吸底时让操作回到表单文流。字段与错误提示滚动到键盘上方，不能用固定 100vh 把按钮压到键盘下。
滚动边界
不让 header / footer 遮住首末字段；内层滚动结束不滚动背景。避免同一屏出现两个相邻的长列表滚动区。

键盘视口处理参考 MDN VisualViewport，窄屏不通过缩小整页字号适配。

04

响应式内容优先级

≤767px手机 / 4 栏

单列内容、16px 页边距。表单字段一列；主要操作保持 44px 触摸高度。详情与列表切换后保留返回上下文。

768–1199px平板 / 8 栏

24px 页边距、收窄导航。筛选栏可以换行；文字与控件不压缩。次栏低于约定最小宽度时提前换行。

≥1200px桌面 / 12 栏

32px 页边距。内容在剩余工作区居中，最大宽度使用页面类型 token；大屏不整体放大字体与图标。

列表与表格

手机优先显示对象、金额、状态和主要操作；时间、编号、详情进入可展开行。需要横向比较的完整表格放在局部可滚动容器，并有可见滚动提示。

筛选与批量动作

搜索保留在列表上方；复杂筛选收进抽屉，入口显示已选数量。批量操作只在选中后出现，提供取消选择，不能遮挡记录末行。

文字与数字

标题自然换行且无末尾标点；金额与单位保持关联，极长数值降低一个字号级别后允许合理换行。地址、UID 可断行与复制，完整详情不省略。

触摸与放大

触摸设备不依赖 hover 显示按钮或关键提示；使用点击展开。200% 文本放大时控件自适应增高，不裁掉文字。布局最窄覆盖 320px。

05

校验、反馈与未保存内容

校验时机

初始不显示错误；首次离开已填写字段时校验，提交时检查全部。错误出现后随有效修改更新；提交失败将焦点移到首个错误，关联错误说明。

普通 Toast

复制、保存等非关键反馈显示 5 秒，可手动关闭；悬停或键盘焦点停留时暂停计时，最多同时 3 条。同一事件合并，不重复刷屏。

错误持续可见

字段错误留在字段下，直到修正。页面错误提供重试；重要交易结果保留在页面或记录里。Toast 不作为失败、付款结果和权限原因的唯一入口。

可中断的修改

只有值发生变化才标记未保存。放弃确认提供继续编辑与放弃修改；保存失败保留草稿。即时生效的主题、筛选不再叠加保存确认。

动效与等待

加载保留原空间，操作按钮保持宽度。常规反馈沿用现有按钮时长，浮层 220ms / 8px；减少动态偏好下取消位移动画。结果改变用文字和图标同步表达。

禁止假成功

提交、处理中与成功是三个独立状态。只有得到对应结果才更新完成态；超时或断线保留对象标识供重试或查询，不自动清空内容。

持续错误与非打断式通知参考 WAI-ARIA Alert 模式；5 秒仅用于可在页面再次确认的普通反馈。

使用共同断点、浮层层级和反馈 token，避免页面各自定义一套行为INTERACTION RULES
